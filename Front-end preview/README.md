# LiveRoom

A mobile-first React + TypeScript prototype for finding secondhand furniture near UC San Diego. It uses Vite, Tailwind, Framer Motion, lucide-react and Three.js.

## Run

Use Node.js 20 or newer.

```sh
npm ci
npm run dev
npm run build
npm run preview
```

Use an HTTPS origin on iPhone for microphone access. Open the production build online once and allow the service worker to install before disconnecting. Typed search, example chips, photos, sample models and the orbit viewer then work offline. Browser speech recognition may still require a network connection. Triple-tap the LiveRoom wordmark to switch to the six-item demo catalog.

## Demo walkthrough

Search for “a desk lamp and a small side table, under $40, warm wood vibe.” Rotate to landscape to show the parsed query and pipeline. Tap **See it in your room** on a result. Safari may prompt for a second tap after the scan to open Quick Look. Other browsers open a drag-to-rotate preview. Swipe cards right to save or left to skip, or use the visible controls. Open the Craigslist search from the detail sheet to see the projected demo impact increment once per item.

## Data and spatial assets

- `src/data.ts` contains the typed fixture catalog, local intent parser and replaceable `ListingSource` interface. The pipeline visualizes these local steps. Integrations for live listings, Gemini, Neon and ElevenLabs can be added behind the search and voice interfaces.
- Photos are generated sample imagery. USDZ files are dimensioned sample geometry, generated by `python3 scripts/models.py`. Replace both with verified seller assets, actual item models and post URLs for a real inventory feed. The detail sheet currently links to Craigslist searches.
- Apple Quick Look controls placement. The browser can detect a return to the page, and it has no placement or LiDAR telemetry. The celebration plays on return or on entry to the fallback viewer. The fit diagram compares the item footprint to an 8 × 6 ft reference area.
- Impact totals are illustrative and persist locally. The demo credits a listing when its search is opened.

## Buyer-first revision

Start with typed search or **Talk to search**. In iPhone Safari over HTTPS, tap the item’s **See it in your room** link to open Quick Look directly. Other browsers offer an orbit preview. Each card has a QR action and a direct item page. Pipeline and Impact are available from the bottom navigation. See NOTES.md for API integration and the database contract.
